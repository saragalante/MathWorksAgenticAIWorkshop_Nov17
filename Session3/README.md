# Modeling the U.S. Economy Workshop

This package contains the workshop starting point, five exercise checkpoints,
and the exercise instructions with copyable prompts.

## Start here

Begin with [checkpoint 0](checkpoint-0/README.md). Its README explains the
starting report, the supplied historical data, and the MATLAB release and
toolboxes needed to run it.

Open [`workshop_exercises.m`](workshop_exercises.m) in MATLAB for the exercise
instructions, timings, and copyable prompts. The checkpoint folders are
snapshots of the materials at each workshop stage; each README describes its
contents and the run, validation, or build details available for that stage.

## Checkpoint sequence

- [checkpoint-0/](checkpoint-0/README.md) is the supplied starting point.
- [checkpoint-1/](checkpoint-1/README.md) follows Exercise 1: Prepare the Live
  Script and Project.
- [checkpoint-2/](checkpoint-2/README.md) follows Exercise 2: Migrate the
  Report.
- [checkpoint-3/](checkpoint-3/README.md) follows Exercise 3: Test Numerical
  Behavior.
- [checkpoint-4/](checkpoint-4/README.md) follows Exercise 4: Inspect Coverage.
- [checkpoint-5/](checkpoint-5/README.md) follows Exercise 5: Create a Build
  File.
